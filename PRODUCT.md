# Product

## Platform
web
## Users
Security and engineering responders inspecting how a vulnerable dependency reaches their services and whom to notify. Inferred audience from the requested incident workflow; hackathon judges evaluate this synthetic demo.
## Product Purpose
When a dependency is hit, show all connected affected layers at once and notify the workspace admin by email. Confirmed by the user.
## Capabilities and Constraints
Real npm/OSV dependency data joined to synthetic Lagos Ledger services, ownership and on-call. FalkorDB powers Cypher paths, durable investigation memory and shared agent evidence. Deterministic mode works without an AI key; optional model output must be graph-grounded. Monitoring checks published advisories about every30minutes; not intrusion detection. Real email delivery verified to the approved admin inbox; sending to others needs a verified domain. Existing API interfaces and graph evidence must remain intact.
## Brand Commitments
Blast Radius name. User requested Teampot-level taste and confirmed a clean light interface, dark graph, generous spacing and restrained orange alerts on2026-10-18.
## Evidence on Hand
Existing live app and public repository, end-to-end email test, synthetic company, public vulnerability sources. No customer traction or breach detection claims.
## Product Principles
Show connected impact first. Make every claim traceable. Keep technical evidence available without crowding the main task. Label synthetic data and deterministic mode honestly.

## Routes and First Visit
The explanatory landing page at `/` introduces the dependency-impact problem and the working demo. `/app` is the operating workspace. Existing `/?advisory=…` email links redirect to the matching incident in `/app`. The public landing page labels its illustrative graph overview and the fictional Lagos Ledger workspace.
